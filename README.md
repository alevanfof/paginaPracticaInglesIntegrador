# StudyMate — práctica oral de Inglés I

Sitio estático para practicar la entrevista del proyecto StudyMate. No requiere dependencias ni un proceso de compilación.

## Archivos

- `index.html`: aplicación de práctica.
- `audios/integrador_job_interview.mp3`: audio utilizado por el reproductor.

Mantené el MP3 dentro de `audios/`; el HTML usa esa ruta relativa.

## Ejecutar localmente

Abrí `index.html` en un navegador. Si el navegador bloquea el audio al abrir archivos locales, serví esta carpeta con cualquier servidor estático.

## Publicar en Vercel

Importá el repositorio en Vercel y usá la raíz del repositorio como directorio del proyecto. No hay comando de build ni carpeta de salida adicional: es un sitio HTML estático.
